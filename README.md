# ARP Spoofing Detection Using Deep Learning

## About
A deep learning-based system for detecting ARP spoofing attacks in network traffic.

## Features
- ARP spoofing detection
- Deep learning classification
- XGBoost feature selection
- Model evaluation
- Streamlit web interface

## Technologies
- Python
- TensorFlow/Keras
- Scikit-learn
- XGBoost
- Streamlit
- Pandas
- NumPy

## Accuracy
**92.31% test accuracy**

```bash
pip install -r requirements.txt
streamlit run app.py
